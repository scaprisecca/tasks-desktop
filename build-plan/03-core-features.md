## Core Features – Tasks.org Desktop Application

### ✅ Task Management
- Create, edit, complete, and delete tasks
- Task fields:
  - Priority (None, Low, Medium, High)
  - Long-form description
  - List association (from CalDAV)
  - Tags (with unused tag filtering)
  - Start Date & Due Date
  - Recurring Rules (Daily/Weekly/Monthly/Custom)
  - Reminders (by start/due/overdue)
  - Location (optional)
  - Attachments (images, PDFs, etc.)
  - Subtasks (checklist style)

### 🧭 Navigation & Filtering
- Sidebar with:
  - My Tasks
  - Today / Next 7 Days filters
  - Custom user filters
  - Tags (with toggle)
  - Lists (CalDAV-synced)
- Center pane: grouped task list
- Right pane: task detail view with inline editing

### 📅 Calendar View
- Daily, 3-day, Weekly, Monthly views
- Visual layout of tasks
- Clicking tasks opens detail pane

### 🔁 Sync Engine
- CalDAV integration (via `tsdav`)
- Startup sync
- Instant or queued sync (offline-first)
- Auto-resume on reconnect
- Conflict resolution: last-write-wins or manual TBD

### ⚙️ System & Platform Features
- Global quick-add shortcut
- Full offline mode with local storage (IndexedDB or SQLite)
- Sync status indicators
- Linux Mint optimized, future support for Windows/macOS
