## User Roles & Personas – Tasks.org Desktop Application

### 👤 Primary User Persona: The Privacy-Conscious Productivity Enthusiast

**Name:** Alex  
**Tech Level:** Intermediate  
**Platform:** Linux (primarily Mint), also uses Android  
**Main Goal:** Manage tasks efficiently across devices without relying on cloud-based proprietary platforms.

**Profile:**
- Uses the Tasks.org Android app as a daily task manager
- Prefers self-hosted tools like Nextcloud for syncing and storage
- Looks for simplicity and speed over overly complex features
- Wants quick desktop access to add, modify, and complete tasks
- Doesn’t want to deal with terminal commands or config files for setup

**Behavior Patterns:**
- Uses the app throughout the day in short sessions
- Frequently toggles between task views (calendar, today, filters)
- Syncs automatically through Nextcloud/CalDAV (using DAVx⁵ on mobile)
- Occasionally works offline (e.g., during travel), expects tasks to sync later

**Pain Points with Other Platforms:**
- Paid subscriptions and data lock-in
- Poor offline support
- Lack of Linux-first desktop tools
- Overwhelming feature bloat
