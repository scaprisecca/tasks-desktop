## Tasks.org Desktop Application – App Overview

**Name:** Tasks.org Desktop Application

**Description:**  
A cross-platform, offline-first desktop task manager that syncs with CalDAV-compatible services (like Nextcloud) and replicates the core experience of the Tasks.org Android app, designed with a clean, TickTick-style layout. Optimized for Linux Mint, with future Windows/macOS support.

**Primary Goals:**
- Feature parity with the Android app
- Full offline capability
- Seamless CalDAV sync (using libraries like `tsdav`)
- Electron-based cross-platform delivery
- Intuitive, performant, and extensible UI (React + TypeScript)

**Target Users:**
- Linux users looking for a privacy-first task manager
- Existing Tasks.org users wanting desktop sync
- Self-hosters using Nextcloud

**Key Features:**
- Rich task fields (priority, recurrence, tags, reminders, etc.)
- Visual calendar views
- Global quick-add shortcut
- Robust sync handling and offline queueing
- Keyboard-first navigation and UI interactions
