## Third-Party Libraries – Tasks.org Desktop Application

### 🖥 UI & Styling
- [`react`](https://reactjs.org/) – UI library
- [`react-dom`](https://reactjs.org/) – React renderer for the web
- [`tailwindcss`](https://tailwindcss.com/) – Utility-first CSS framework
- [`classnames`](https://www.npmjs.com/package/classnames) – Conditional class management

### ⚛️ State Management
- [`zustand`](https://github.com/pmndrs/zustand) – Global state store

### 🔁 CalDAV Sync
- [`tsdav`](https://github.com/andrytsenko/tsdav) – TypeScript DAV/CalDAV/WebDAV client

### 💾 Storage & Offline Sync
- [`dexie`](https://dexie.org/) – IndexedDB wrapper with rich query support and sync tooling
- [`electron-store`](https://github.com/sindresorhus/electron-store) – File-based storage for credentials/settings

### 🔒 Security & Encryption
- [`crypto.subtle`](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto) – Web Crypto API (built-in) for encrypting sensitive data

### 📦 Packaging & Electron Tools
- [`electron`](https://www.electronjs.org/) – Cross-platform desktop runtime
- [`electron-builder`](https://www.electron.build/) – App packaging and installer generation

### ⚙️ Build & Dev Tools
- [`vite`](https://vitejs.dev/) – Fast development bundler
- [`typescript`](https://www.typescriptlang.org/) – Static typing
- [`eslint`] – Linting for consistent code style
- [`prettier`] – Auto-formatting for clean and readable code
- [`vite-plugin-pages`](https://github.com/hannoeru/vite-plugin-pages) (optional) – File-based routing
