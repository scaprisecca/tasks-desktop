## User Flows – Tasks.org Desktop Application

### 🧭 Primary User Flows

1. **Add a New Task**
   - Via global quick-add (system shortcut)
   - Or from within the app UI

2. **Edit a Task**
   - Modify description, due date, priority, etc.
   - Add/remove subtasks or attachments

3. **Mark Task as Complete**
   - From list view or task detail view
   - Visual feedback + auto sync

4. **Filter Tasks**
   - Use quick filters: Today / Next 7 Days
   - Use custom saved filters and tag views

5. **View Calendar**
   - Switch to visual calendar mode
   - Navigate by day, week, month
   - Click task to open detail

6. **Sync with CalDAV**
   - Sync on app startup
   - Auto-sync changes (online)
   - Queue and retry changes (offline)

7. **Setup CalDAV Account**
   - Enter server URL, username, password
   - Handle 2FA / app password gracefully

8. **Work Offline**
   - Open app with no connection
   - Create/edit/complete tasks
   - Sync queued changes when online
